# winston-agent-pilot

A small, made-up project used to pilot an AI coding agent. Nothing here is real business data.

`listing_tools` has helpers for a real-estate photography workflow: formatting shoot dates, pricing photo packages,
and turning property addresses into folder names.

## Run the tests

```bash
python3 -m unittest discover -s tests
```

No packages to install; Python 3.9 or newer.
